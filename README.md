## 📖 Sobre

O **BookList** é o meu espaço para registrar livros, acompanhar leituras e guardar obras que quero conhecer. A ideia é manter tudo organizado em um só lugar e facilitar a escolha da próxima aventura literária. ✨

## 💡 Como adicionar um livro

1. Clique em **Edit this file** no GitHub.
2. Adicione o livro na seção correspondente.
3. Marque itens concluídos trocando `[ ]` por `[x]`.
4. Clique em **Commit changes** para salvar.
